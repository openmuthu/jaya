## Acquisition Plan

### Approach
The project stores texts as **UTF-16 LE** encoded `.txt` files in ITRANS-named folders. To add a new text from Wikisource:

1. **Download** the wikitext/plain text from Wikisource (Special:Export or API)
2. **Extract** the Devanagari prose (strip wiki markup)
3. **Convert** to UTF-16 LE encoding
4. **Place** in the appropriate folder using the existing ITRANS naming convention
5. Add a `.kw` keyword file alongside if the text needs tagging (optional)

A Python helper script outline is given below.

## Acquisition Script (Python)

The following script can download a Wikisource text, strip wiki markup, and write it as UTF-16 LE:

```python
#!/usr/bin/env python3
"""
Usage: python3 fetch_wikisource.py "पृष्ठनाम" output/path/file.txt
Fetches a Wikisource Sanskrit page and saves as UTF-16 LE.
"""
import sys, re, urllib.request, urllib.parse, json

def fetch_wikitext(title):
    api = "https://sa.wikisource.org/w/api.php"
    params = urllib.parse.urlencode({
        "action": "query", "titles": title,
        "prop": "revisions", "rvprop": "content",
        "format": "json", "formatversion": "2"
    })
    with urllib.request.urlopen(f"{api}?{params}") as r:
        data = json.load(r)
    page = data["query"]["pages"][0]
    return page.get("revisions", [{}])[0].get("content", "")

def strip_markup(wikitext):
    # Remove templates {{...}}
    text = re.sub(r'\{\{[^}]*\}\}', '', wikitext, flags=re.DOTALL)
    # Remove file/category links
    text = re.sub(r'\[\[(?:File|Category|चित्र|वर्गः):[^\]]*\]\]', '', text, flags=re.I)
    # Convert wikilinks [[X|Y]] → Y, [[X]] → X
    text = re.sub(r'\[\[(?:[^|\]]*\|)?([^\]]+)\]\]', r'\1', text)
    # Remove HTML tags
    text = re.sub(r'<[^>]+>', '', text)
    # Remove headers markup but keep the text
    text = re.sub(r'=+\s*(.*?)\s*=+', r'\1', text)
    # Clean extra blank lines
    text = re.sub(r'\n{3,}', '\n\n', text)
    return text.strip()

def save_utf16le(text, path):
    import os
    os.makedirs(os.path.dirname(path) or '.', exist_ok=True)
    with open(path, 'wb') as f:
        f.write(b'\xff\xfe')          # UTF-16 LE BOM
        f.write(text.encode('utf-16-le'))
    print(f"Saved {len(text)} chars → {path}")

if __name__ == "__main__":
    title, outpath = sys.argv[1], sys.argv[2]
    raw   = fetch_wikitext(title)
    clean = strip_markup(raw)
    save_utf16le(clean, outpath)
```

## Naming Convention (ITRANS)

The project uses ITRANS transliteration for file and folder names. Key rules:
- Long vowels: `A` = ā, `I` = ī, `U` = ū, `E` = ē, `O` = ō
- Retroflex: `T`, `D`, `N`, `Sh`
- Aspirates: `kh`, `gh`, `ch`, `jh`, `Th`, `Dh`, `th`, `dh`, `ph`, `bh`
- Anusvara: `M`; Visarga: `H`
- Use camelCase for compound words (e.g., `taittirIyasaMhitA`)
